# Команда КофеДней

Лендинг для набора команды фестиваля [«КофеДни в Воронеже»](https://coffeedaysvrn.ru/): координаторы, волонтёры, контент, партнёрства.
Заявки из формы попадают в Google Таблицу.

**Сайт:** https://sergeystarodubtcev.github.io/coffeedays/

Статический сайт без сборки: `index.html`, `styles.css`, `app.js`, `config.js`. Фото и логотипы взяты с coffeedaysvrn.ru и лежат в `assets/`.

## Подключение Google Таблицы (5 минут)

1. Создайте новую [Google Таблицу](https://sheets.new), например «КофеДни — заявки в команду».
2. Откройте **Расширения → Apps Script**.
3. Удалите содержимое `Code.gs` и вставьте код из [`google-apps-script/Code.gs`](google-apps-script/Code.gs). Сохраните (💾).
4. В выпадающем списке функций выберите `setup` и нажмите **▶ Выполнить**. Разрешите доступ. Если Google покажет «Приложение не проверено», нажмите «Дополнительно → Перейти».
   В таблице появится лист **«Заявки»** с заголовками и колонкой «Статус».
5. **Начать развёртывание → Новое развёртывание**, тип **«Веб-приложение»**:
   - Запуск от имени: **Я**
   - У кого есть доступ: **Все**
6. Скопируйте URL веб-приложения (`https://script.google.com/macros/s/…/exec`) и вставьте его в [`config.js`](config.js):
   ```js
   SCRIPT_URL: "https://script.google.com/macros/s/…/exec",
   ```
7. Закоммитьте изменения. Через минуту сайт обновится, и заявки начнут поступать в таблицу.

> Если вы потом меняете код скрипта, делайте **Управление развёртываниями → ✏️ → Новая версия**, тогда URL останется прежним.

### Уведомления о новых заявках (необязательно)

В Apps Script: **Настройки проекта → Свойства скрипта**:

| Свойство | Значение |
|---|---|
| `NOTIFY_EMAIL` | почта (можно несколько через запятую) |
| `TELEGRAM_BOT_TOKEN` | токен бота от @BotFather |
| `TELEGRAM_CHAT_ID` | id чата организаторов (бот должен быть добавлен в чат) |

## GitHub Pages

Деплой выполняет GitHub Actions (`.github/workflows/pages.yml`) при каждом пуше.
Если первый запуск упал на шаге `configure-pages`, включите Pages вручную: **Settings → Pages → Build and deployment → Source: GitHub Actions**, затем перезапустите workflow во вкладке **Actions**.

## Что где менять

- Роли и описания: массив `ROLES` в `app.js`.
- Логотипы партнёров: массив `LOGOS` в `app.js` и файлы в `assets/logos/`.
- Тексты, FAQ, контакты: `index.html`.
- Цвета: переменные в начале `styles.css` (палитра coffeedaysvrn.ru).
